# v1.0 Roadmap

**Current package version:** v1.0.0

## v1.0 readiness goals

The project should not be labeled v1.0 until the following are completed:

1. Stable public API for scoring, database, benchmark, validation, sensitivity, expert review, and project audit modules.
2. Curated real-case validation with official-source citation verification.
3. Documented sensitivity analysis for borderline and high-impact cases.
4. Expert review protocol finalized; any actual interviews handled under appropriate institutional review requirements.
5. Manuscript claims aligned with repository capabilities.
6. Independent final audit completed.
7. No redistribution of raw Retraction Watch data or private interview data.
8. Clear release notes, license files, citation metadata, and reproducible tests.

## Possible v1.0 title

Research Integrity Risk Framework: A transparent scoring and evidence-organization toolkit for research-integrity risk assessment.

## Not allowed for v1.0 without additional evidence

- Claiming validated misconduct detection.
- Claiming optimal weights.
- Ranking authors as wrongdoers.
- Treating database matches as official misconduct findings.
