# Publication Roadmap

## Current status

v1.0.0 is the Pre-release Consolidation and Project Integration Release. It retains scoring, database integration, benchmark, real-case validation infrastructure, manuscript planning, weight sensitivity analysis, and expert review protocol layers, and adds project-level integration documents, an API reference, final audit checklists, repository-manuscript mapping, and a v1.0 roadmap. It is not a completed empirical validation study, not a completed expert-review study, and does not claim empirically optimized weights.

## Recommended publication path

### Stage 1. Method paper framework

Prepare title, abstract, outline, introduction, methods, limitations, ethics, and figure plan.

### Stage 2. Reference verification

Add verified citations to:

- retraction databases
- publication ethics literature
- research misconduct definitions
- post-publication peer review literature
- meta-research and retraction studies
- database curation literature

### Stage 3. Empirical validation

Build a real-case benchmark set with formal records. Do not claim empirical validation before this stage.

### Stage 4. Expert review and calibration protocol

Use the v0.8 expert review protocol to conduct semi-structured interviews, structured weight surveys, and Delphi-style feedback. Consult institutional review requirements before collecting interview data for publishable research.

Send the framework to independent reviewers for methodological and ethical feedback.

### Stage 5. Preprint or manuscript submission

Only after references, benchmark validation, and independent review are complete.

## Claims allowed at v1.0.0

Allowed:

- The framework is open-source and rule-based.
- The framework includes modular scoring, database integration, and synthetic benchmark testing.
- The framework is intended for preliminary risk assessment and evidence organization.

Not allowed:

- The framework is empirically validated.
- The framework detects fraud.
- The framework confirms misconduct.
- The framework identifies serial misconduct without formal records and identity confirmation.


## v0.7-alpha: Weight Sensitivity Analysis Release

v0.7-alpha introduced weight-profile comparison, one-at-a-time perturbation analysis, and rank-stability summaries. This stage should be used to identify cases whose classifications depend heavily on the pilot weighting scheme.

v1.0.0 retains the v0.7 sensitivity-analysis layer and does not complete empirical calibration. Future versions should still use expert review, curated real-case validation, and sensitivity reports before manuscript submission.
