# Manuscript Audit Checklist

## Manuscript version

- Version:
- Date:
- Auditor:
- Decision: Verified / Needs Revision / Unsupported / Risky Claim

## 1. Source verification

- [ ] Every factual background claim has a citation.
- [ ] Every numerical claim has a citation.
- [ ] Every database description is accurate.
- [ ] Public records are distinguished from formal determinations.

## 2. Claim boundary

- [ ] The manuscript does not claim to detect fraud.
- [ ] The manuscript does not claim empirical validation unless real-case benchmarks are included.
- [ ] The manuscript does not equate retraction with misconduct.
- [ ] The manuscript does not equate name match with author identity.

## 3. Methods consistency

- [ ] The nine modules match the repository documentation.
- [ ] The weights match `src/scoring.py`.
- [ ] C0–C7 definitions match the code.
- [ ] C4–C7 hard overrides match the code.

## 4. Ethics and misuse risk

- [ ] No public accusation language.
- [ ] Limitations are explicit.
- [ ] Misuse safeguards are explicit.
- [ ] Second-pass verification is described.

## 5. Release decision

- [ ] Verified
- [ ] Needs Revision
- [ ] Unsupported
- [ ] Risky Claim
