# Data Use Notice

This repository does not redistribute Retraction Watch data or other third-party databases.

Users should obtain current data from official sources, including:

- Crossref Retraction Watch data: https://gitlab.com/crossref/retraction-watch-data
- Retraction Database search: https://retractiondatabase.org/RetractionSearch.aspx
- Journal and publisher webpages
- Crossref/Crossmark records
- PubMed records
- PubPeer pages
- University, funder, or institutional notices

## Important Access Boundary

The Retraction Database web search may require manual verification and may not be reliably accessible as a programmatic data source. Users should not assume that a web-search result page can be automatically parsed or treated as complete without manual checking.

## Data-Use Responsibility

Users are responsible for complying with the data-use terms of each source. This framework organizes evidence and risk signals; it does not replace official databases, journal notices, or institutional investigations.


## v0.4 CSV Integration

The `src.database` module can read a local Retraction Watch CSV file supplied by the user. This repository does not redistribute the dataset.
