# References Plan

Current package version: v1.1-prep.1.

This file is a planning scaffold for future citation verification. It does not claim that the manuscript is submission-ready.

## Citation categories to verify before submission

1. Retraction database and metadata sources
   - Crossref Retraction Watch data source
   - Retraction Database search interface
   - Crossmark / journal correction and retraction notices

2. Research-integrity guidance
   - Retraction and correction guidance
   - Publication ethics guidance
   - Misconduct definitions and institutional-review boundaries

3. Methodological foundations
   - Risk-scoring frameworks
   - Expert-prior weighting and Delphi-style calibration
   - Sensitivity analysis and benchmark validation

4. Domain-specific data-integrity issues
   - Image integrity in biomedical research
   - Statistical inconsistency and p-value reporting concerns
   - Raw-data availability and reproducibility

## Required citation verification steps

- Confirm each source directly from the official publisher or organization page.
- Record DOI, URL, publication year, and access date when applicable.
- Avoid citing secondary summaries when primary guidance is available.
- Do not cite a source as supporting claims stronger than the source actually supports.
- Separate empirical claims from methodological or ethical-positioning claims.

## Boundary

This project currently provides manuscript scaffolding only. Citation verification is mandatory before preprint posting, class submission, or journal submission.
