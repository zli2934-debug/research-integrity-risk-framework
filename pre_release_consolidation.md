# Pre-release Consolidation

**Current package version:** v1.0.0  
**Purpose:** consolidate the alpha-stage framework before v1.0 planning.

## Scope

v1.0.0 integrates the following layers without changing the core risk-scoring philosophy:

1. Rule-based scoring and C0-C7 classification.
2. Retraction Watch CSV evidence organization.
3. Synthetic benchmark testing.
4. Real-case validation infrastructure.
5. Weight sensitivity analysis.
6. Expert review and calibration protocol.
7. Manuscript scaffolds and citation-planning files.
8. Release-readiness and final-audit checklists.

## Non-goals

v1.0.0 does not claim completed empirical validation, expert consensus, optimal weighting, author identity confirmation, or misconduct adjudication.

## Required before v1.0

- Curated real-case validation with verified official notices.
- Citation verification for manuscript claims.
- Independent review of model logic and ethical safeguards.
- Documentation cleanup and stable API surface.
