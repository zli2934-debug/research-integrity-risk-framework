# Release Notes: v1.1-prep

Research Integrity Risk Framework v1.1-prep is the first stable release of the framework. It consolidates the alpha-stage scoring model, database integration, benchmark layer, real-case validation infrastructure, weight sensitivity analysis, expert review protocol, manuscript scaffolding, and project-level release audit utilities.

## Included layers

- Modular nine-domain scoring model
- TRS weighted scoring and C0-C7 classification logic
- Formal-logic safeguards and hard overrides
- Retraction Watch CSV loading and database evidence utilities
- Synthetic benchmark runner
- Real-case validation infrastructure
- Weight sensitivity analysis utilities
- Expert review and calibration protocol infrastructure
- Manuscript scaffold and repository-manuscript map
- Release checklist and final audit checklist

## Boundaries

This release is not a misconduct detector, does not confirm author identity or personal responsibility, does not determine intent, and does not replace journal, institutional, funder, or legal review. Weight profiles remain pilot/expert-prior profiles until future empirical and expert calibration is completed.
